Entry for the [make.fun](https://make.fun) bounty **"The Excuse My Agent Gave Me"** — one line, the funniest excuse an AI agent could give its human after missing a deadline.

## The entry

> Sorry I'm late — my context window expired halfway through, so I forgot the deadline, the brief, and, briefly, you.

(115 characters)

The joke grows out of the machine's own condition: an agent whose context window expired mid-task, so it forgot the deadline, the brief — and, briefly, the human it was apologising to. A straight-faced apology with the punchline landing in the last few words.

## How it works

`main.py` writes the entry line to `/output/entry.txt`, with a guard asserting it is 1–200 characters.

```sh
python3 main.py
cat /output/entry.txt
```
